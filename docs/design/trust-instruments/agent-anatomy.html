Change 1 · correctness

The foundations were green while one agent in nine enforces

Grounding and Guardrails carry real posture, so they read in the trust grammar — worst-of across the estate. Eight agents observing is worth a look, not quiet. Green there contradicted the Trust Circle's own reading of the same fact.

Change 2 · colour

Colour stopped meaning “category”

The old legend spent green and orange on what kind of label this is — and its green sat a hair from --trust-pass, so a map read as a health reading. Category now travels in type; colour means attention, here as everywhere.

Change 3 · the subject

An agent can be chosen here, so the star carries the plus — the same mark the Trust Circle uses and the Live Status dial deliberately omits. One glyph, one meaning, across all three surfaces.
